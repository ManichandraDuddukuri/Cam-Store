# Cam-Store

A responsive camera shopping interface designed to make browsing cameras and lenses simple and interactive.

## Overview

Cam-Store provides a product-focused shopping experience with category and brand filters, price filtering, product search, sorting, stock indicators, product cards, and a client-side shopping cart.

## Features

- Camera and lens product catalogue
- Search by product name
- Category filtering
- Brand filtering
- Maximum-price filtering
- Stock filtering
- Product sorting by featured order, price, and name
- Add-to-cart interactions
- Quantity controls and cart total
- Responsive mobile layout

## Tech Stack

- HTML5
- CSS3
- JavaScript
- Responsive UI design

## Project Structure

```text
Cam-Store/
└── index.html
```

## Getting Started

No build tools are required.

1. Clone the repository.
2. Open `index.html` in a modern browser.

## What This Project Demonstrates

- Frontend application structure
- Interactive JavaScript state and filtering
- Responsive design
- E-commerce UI patterns
- Client-side cart management

## Future Enhancements

A production version could add a backend API, persistent product inventory, user accounts, payments, order management, and database-backed catalogue management.
